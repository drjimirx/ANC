# JMed


## Features
- ANC Calculator
- BMI Calculator
- Morse Code encrypt and decrypt
- AES 256 Based data encryption





## Install on Phone/Tablet

**Android (Chrome):**
1. Open in Chrome → tap ⋮ menu → Add to Home screen → Install

**iPhone (Safari):**
1. Open in Safari → tap Share → Add to Home Screen

## Offline Use
After first load, the app works fully offline.
